# Cheeseberry

## Getting Started

Install [git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) and [just](https://just.systems/man/en/chapter_4.html).

Then, run the following command:

```sh
just bootstrap
```

To run the codebase, run the following command:

```sh
just run
```

To check out the commands, run the following command:

```sh
just
```
